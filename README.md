# 굿바이브 (PWA)

달력별 체크리스트 + 카테고리 + 루틴 + 리마인더가 있는 하루 계획 앱. 서버 없이 단일 HTML로 동작하며, 데이터는 기기(localStorage)에 저장됩니다.

## 파일
- `index.html` — 앱 전체 (CSS/JS 포함)
- `manifest.json` — 홈 화면 추가용 PWA 설정
- `sw.js` — 오프라인 캐시 + 알림 클릭 처리
- `icon-*.png` — 앱 아이콘 (`node make-icons.js`로 재생성)

## 로컬에서 열기
```bash
npx -y serve -l 5180 .
```
→ http://localhost:5180

## 아이폰에 설치
1. HTTPS 주소(GitHub Pages, Vercel 등)에 올린다.
2. Safari로 열고 공유 → **홈 화면에 추가**.
3. 홈 화면 아이콘으로 열고 메뉴 → 리마인더 관리 → **알림 허용하기**.

## 기능
- 주간 달력 + 월 달력 점프, 요일별 남은 개수 표시
- 카테고리 등록/편집/색상/드래그 순서 변경
- 할 일: 메모(여러 줄), 날짜, 카테고리 이동, 개별 알림 시각, 삭제
- 드래그(≡ 손잡이)로 우선순위 정렬, 완료한 항목은 자동으로 맨 아래
- 루틴: 카테고리·기간(기한)·반복 요일·매일 알림 시각, 하루만 빼기/여기서 끝내기
- 리마인더: 매일 정해진 시각에 "오늘 남은 할 일" 알림
- 백업: JSON 복사/파일 저장/복원

## 알림 제약
브라우저(PWA) 특성상 앱이 열려 있거나 최근 열렸을 때 알림을 확인해서 보냅니다.
앱이 완전히 꺼진 상태에서 정확한 시각에 받으려면 웹 푸시 서버(예: Supabase Edge Function + cron)가 필요합니다.
