취소설치

설치(또는 추가)를 눌러요홈 화면에 노란 체크 아이콘이 생겨요

잘 안 될 때

  • "홈 화면에 추가"가 안 보여요 — 카카오톡·인스타그램·네이버 앱 안에서 링크가 열린 거예요. 그 화면 오른쪽 위 ⋮ 또는 공유 → "다른 브라우저로 열기" / "Safari로 열기"를 누른 뒤 다시 해 보세요.
  • 알림을 받고 싶어요 — 홈 화면 아이콘으로 앱을 연 뒤 ☰ 메뉴 → 리마인더 관리 → 알림 허용하기. 아이폰은 반드시 홈 화면 아이콘으로 열어야 알림 권한을 물어봐요.
  • 폰과 컴퓨터를 같이 쓰고 싶어요 — ☰ 메뉴 → 구글로 로그인. 같은 구글 계정으로 로그인한 기기끼리 할 일이 똑같이 맞춰져요.
  • 아이콘을 지웠어요 — 데이터는 남아 있어요. 위 순서대로 다시 추가하면 그대로 나와요.
